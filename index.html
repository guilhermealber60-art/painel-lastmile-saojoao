Publicar direto no GitHub

Com um token configurado, o botão Publicar envia data/orders.json, data/report.json e data/gestores.json direto para o repositório guilhermealber60-art/painel-lastmile-saojoao — sem baixar arquivo, sem git, sem terminal.

Segurança: o token fica salvo só neste navegador (não é enviado a mim nem a ninguém além do GitHub). Crie um fine-grained token em github.com/settings/tokens, restrito ao repositório painel-lastmile-saojoao, com permissão apenas de Contents: Read and write, e defina uma expiração. Se trocar de computador ou navegador, precisa configurar de novo.
